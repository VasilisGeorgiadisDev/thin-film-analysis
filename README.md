# Thin-film analysis-BSc thesis

Developed for a BSc thesis on Li₄Ti₅O₁₂ electrochromic films at the
Department of Physics, University of Patras. 

Automated analysis of electrochemical and optical measurements on thin films.
Raw instrument files go in; Excel workbooks with ready-made, native Excel charts
come out.

| Analysis | Input | Output |
|---|---|---|
| Cyclic voltammetry (CV) | NOVA `.xlsx` exports | current density vs potential, charge density, areal capacitance (mF/cm²) |
| CV cycling stability | several NOVA rounds of one long run | the same, at chosen cycles of the run (e.g. 4, 25, 50, 75, 100) |
| Galvanostatic charge–discharge (GCD) | NOVA `.xlsx` exports, one per current density | potential vs time, IR drop, areal capacitance from the linear part of the discharge |
| Transmittance | PerkinElmer `.asc` spectra | %T at 550 nm for every spectrum, in one `.dat` table |
| Film thickness | stylus profilometer `.dat` scans | thickness, with the measured window drawn on every profile |


**Runs on Windows** (10 or 11). It has not been tested on macOS or Linux.

## Quick start

1. **Install Python 3.10 or newer** from <https://www.python.org/downloads/>.
   During setup, tick *Add python.exe to PATH*.
2. **Download this repository** (*Code → Download ZIP*). Right-click the ZIP →
   *Extract All*. Running it from inside the ZIP does not work.
3. **Start the menu:** double-click `run.bat`.

   Windows may warn that the file comes from the internet. Choose *Run*, or
   *More info → Run anyway*.

   The first time, the menu offers to install the three libraries it needs
   (`numpy`, `openpyxl`, `matplotlib`). Press Enter; an internet connection is
   needed for this step only.
4. **Try it on the example data.** The download includes synthetic measurements
   for two samples, `EX1` and `EX2`, so every analysis in the menu works straight
   away. See [Example data](#example-data).
5. **Describe your own samples** in `samples.xlsx`, which the menu creates from
   `samples_template.xlsx` on its first run. One row per sample.
6. **Add your measurements** under `data/`, one sub-folder per sample (see below),
   and run the menu again. The result opens by itself and is saved under
   `results/`.

## Folder layout

```
thin-film-analysis/
├── run.bat                  double-click on Windows
├── menu.py                  the menu
├── samples_template.xlsx    the sample table, with the two example rows
├── samples.xlsx             your sample table (created on first run)
├── analysis/                the four analysis scripts
├── data/
│   ├── CV/S12/...           one sub-folder per sample
│   ├── GCD/S12/...
│   ├── Transmittance/S12/...
│   └── Thickness/S12/...
├── tools/make_examples.py   generates the synthetic example data
└── results/                 everything the analyses produce
```

Each folder under `data/` has a `README.md` with the exact file format and naming
it expects: [CV](data/CV/README.md) · [GCD](data/GCD/README.md) ·
[Transmittance](data/Transmittance/README.md) · [Thickness](data/Thickness/README.md).

Your own measurements, `samples.xlsx` and `results/` are listed in `.gitignore`,
so they are never uploaded if you put the folder under Git.

## Example data

`data/*/EX1` and `data/*/EX2` hold **synthetic** files: they imitate the exports of
the instruments but are **not measurements**. Every file name ends in `synthetic`.
They were generated by `tools/make_examples.py` with these values:

| | EX1 | EX2 |
|---|---|---|
| Film thickness | 300 nm | 500 nm |
| Transmittance at 550 nm | 82.0 % | 74.0 % |
| GCD capacitance at 0.2 mA/cm² | 32 mF/cm² | 48 mF/cm² |
| CV | 10, 20 and 50 mV/s | 50 mV/s, plus 2 × 50 cycles |

Every analysis gets them back, except thickness: it reports about **314 nm** and
**513 nm**. The synthetic substrate is slightly tilted, as real ones often are,
and the tilt adds a few nanometres between the step and the measured window —
a live example of why the thickness charts must be checked.

When you add your own samples, delete the `EX1` and `EX2` folders under `data/`
and their two rows in `samples.xlsx`.

## The sample table

The analyses take the area and the description of each sample from
`samples.xlsx`. Its first sheet needs a header row with at least *Sample* and
*Area (cm²)*:

| Column | Needed | Meaning |
|---|---|---|
| **Sample** | yes | the sample name exactly as it appears in the file names, e.g. `S12` |
| **Alias** | no | a second name some files use for the same sample |
| **Area (cm²)** | for CV and GCD | active film area; every mA/cm² and mF/cm² depends on it |
| **Layers** | no | number of deposited layers |
| **Additive** | no | e.g. `yes`/`no`, or the additive's name |
| **Solution age** | no | e.g. `same day`, `2 days`, `1 week`; samples are sorted by it |
| **RPM** | no | spin speed |

**Sample names** are one to three letters followed by a number, e.g. `S12`, `A1`,
`LTO5`. The analyses find them inside the file names this way, so a name such as
`Film-A` or `sample12` is not recognised.

Results always use the *Sample* name, even when a file is named after the *Alias*.

## Film thickness: check the result

The thickness is read automatically from the flat part of the profile right after
the step edge. **This is not always accurate.** A strongly tilted sample, a rough
film or pile-up at the edge can mislead the detection.

- Every sample gets its own chart in the results, with the measured window drawn
  in red. **Look at it.**
- The analysis prints a warning when the sample tilt makes the value uncertain.
- If a window is in the wrong place, the menu asks whether to correct it: type
  `SAMPLE=X0:X1` with the positions in µm, e.g. `S12=1221:1317`, and the analysis
  runs again with that window.

## Settings

The first lines of `menu.py`:

| Setting | Default | Meaning |
|---|---|---|
| `ELECTROLYTE` | `"AlCl3"` | used in titles when a file name does not say |
| `DEFAULT_SCAN` | `"4"` | the CV cycle compared when you just press Enter |
| `STYLE` | `"report"` | `"report"` for worksheet charts, `"paper"` for publication-style figures |
| `PNG` | `True` | also save every chart as an image |

## Command line

Every script in `analysis/` also runs on its own; `--help` lists all options.

```bash
python analysis/cv_analysis.py data/CV/S12/*.xlsx --scan 4 --samples samples.xlsx
python analysis/gcd_analysis.py data/GCD/S12 data/GCD/S13 --samples samples.xlsx
python analysis/transmittance.py data/Transmittance --samples samples.xlsx
python analysis/thickness_analysis.py data/Thickness --window S12=1221:1317
```

## Supported instruments

The readers are written for the files of these instruments:

- **Potentiostat:** Metrohm Autolab with NOVA, exported to Excel.
- **Spectrophotometer:** PerkinElmer UV/Vis (UV WinLab ASCII export).
- **Profilometer:** stylus profilometer text export with `X Units` / `Z Units`
  header lines and `x,z` pairs.

Files from other instruments need their columns renamed to match, or a new
reader.
